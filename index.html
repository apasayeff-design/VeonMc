# Oyunçu Öldürmə (Kills) Oynama Vaxtı

SERVER QAYDALARI

Hər kəsin rahat və ədalətli oyun oynaması üçün əməl edilməli olan qaydalar.

1. Hile və Kənar Proqramlar

Hər cür hile, x-ray, makro və ya oyunda üstünlük təmin edən kənar proqramların istifadəsi qəti qadağandır (Cəza: Permanently Ban).

2. Hörmət və Təhqir

Digər oyunçulara qarşı təhqir, irqçilik, söyüş və ya aşağılayıcı davranışlar qadağandır. Hər kəsə hörmət göstərilməlidir.

3. Reklam və Spam

Chat-də spam etmək, başqa serverlərin və ya sosial media səhifələrinin reklamını etmək qadağandır.

4. Bug və Xəta İstifadəsi (Exploit)

Oyundakı hər hansı bir xətanı öz xeyrinə istifadə etmək və ya adminlərə xəbər verməmək cəzalandırılır.
